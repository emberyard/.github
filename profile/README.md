# emberyard

Ventures, tools and systems built by one operator and an agent fleet.

## IDX

A Mac cockpit for agentic-AI power users, running over your own Claude Code and Gemini CLI. Chat-first sessions, one-click terminal, per-project windows, approvals, rewind. Signed, notarized and auto-updating. Closed beta.

- [Landing page](https://emberyard.github.io/idx-site/)
- [Release feed](https://github.com/emberyard/idx-releases)

## How we build

- Measured, not guessed: numbers are labelled measured, derived or unverified.
- A ticket key on every commit, squash-merge only, CI-checked changelog.
- Public repos pass an automated audit before anything ships.
